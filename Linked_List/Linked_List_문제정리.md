## Q1. 정렬된 연결 리스트에 값 삽입

원문 위치: 1~2쪽 · 함수: `insertSortedLL`

```c
int insertSortedLL(LinkedList *ll, int item);
```

### 요구사항

정수 하나를 연결 리스트에 삽입하되, **오름차순 정렬 상태를 유지**한다.

- 입력 리스트는 이미 정렬되어 있거나 비어 있다고 가정한다.
- 같은 정수가 이미 존재하면 삽입하지 않는다.
- 성공하면 새 값이 삽입된 **인덱스**를 반환한다. 인덱스는 0부터 시작한다.
- 중복을 포함해 작업에 실패하면 `-1`을 반환한다.

PDF는 사용자 입력을 언급하지만 실제 템플릿에서는 `main()`이 입력받은 값을 `item` 인자로 전달한다.

### 예시

```text
기존: 2 → 3 → 5 → 7 → 9
삽입: 8
결과: 2 → 3 → 5 → 7 → 8 → 9
반환: 4

기존: 5 → 7 → 9 → 11 → 15
삽입: 7
결과: 5 → 7 → 9 → 11 → 15  (변화 없음)
반환: -1
```

## Q2. 두 연결 리스트를 번갈아 합치기

원문 위치: 2~3쪽 · PDF 함수명: `alternateMergeLL`

실제 C 파일의 선언:

```c
void alternateMergeLinkedList(LinkedList *ll1, LinkedList *ll2);
```

### 요구사항

두 번째 리스트의 노드를 첫 번째 리스트의 교대 위치에 삽입한다. 즉, **첫 번째 리스트의 기존 노드 하나마다 그 뒤에 두 번째 리스트의 노드를 하나씩 옮긴다.**

- 첫 번째 리스트에 교대로 삽입할 자리가 있는 동안만 옮긴다.
- 두 번째 리스트에서 옮긴 노드는 제거되고, 남은 노드는 두 번째 리스트에 유지된다.
- 두 번째 리스트가 먼저 소진되면 두 번째 리스트는 비게 된다.
- 첫 번째 리스트의 기존 마지막 노드 뒤에도 하나를 삽입할 수 있다.

### 예시

```text
입력
리스트 1: 1 → 2 → 3
리스트 2: 4 → 5 → 6 → 7

결과
리스트 1: 1 → 4 → 2 → 5 → 3 → 6
리스트 2: 7
```

```text
입력
리스트 1: 1 → 5 → 7 → 3 → 9 → 11
리스트 2: 6 → 10 → 2 → 4

결과
리스트 1: 1 → 6 → 5 → 10 → 7 → 2 → 3 → 4 → 9 → 11
리스트 2: 빈 리스트
```

## Q3. 홀수를 리스트 뒤로 이동

원문 위치: 3쪽 · PDF 함수명: `moveOddItemsToBackLL`

실제 C 파일의 선언:

```c
void moveOddItemsToBack(LinkedList *ll);
```

### 요구사항

연결 리스트의 모든 홀수를 뒤쪽으로 이동한다.

**PDF 예시를 기준으로 홀수끼리, 짝수끼리의 원래 순서를 유지해야 한다.** 숫자 크기순으로 정렬하는 문제가 아니다.

### 예시

```text
입력: 2 → 3 → 4 → 7 → 15 → 18
결과: 2 → 4 → 18 → 3 → 7 → 15

입력: 2 → 7 → 18 → 3 → 4 → 15
결과: 2 → 18 → 4 → 7 → 3 → 15

입력: 1 → 3 → 5
결과: 1 → 3 → 5

입력: 2 → 4 → 6
결과: 2 → 4 → 6
```

## Q4. 짝수를 리스트 뒤로 이동

원문 위치: 4쪽 · PDF 함수명: `moveEvenItemsToBackLL`

실제 C 파일의 선언:

```c
void moveEvenItemsToBack(LinkedList *ll);
```

### 요구사항

연결 리스트의 모든 짝수를 뒤쪽으로 이동한다.

**PDF 예시를 기준으로 홀수끼리, 짝수끼리의 원래 순서를 유지해야 한다.** Q3과 이동 대상만 반대다.

### 예시

```text
입력: 2 → 3 → 4 → 7 → 15 → 18
결과: 3 → 7 → 15 → 2 → 4 → 18

입력: 2 → 7 → 18 → 3 → 4 → 15
결과: 7 → 3 → 15 → 2 → 18 → 4

입력: 1 → 3 → 5
결과: 1 → 3 → 5

입력: 2 → 4 → 6
결과: 2 → 4 → 6
```

## Q5. 앞 절반과 뒤 절반으로 분리

원문 위치: 4~5쪽 · PDF 함수명: `frontBackSplitLL`

실제 C 파일의 선언:

```c
void frontBackSplitLinkedList(
    LinkedList *ll,
    LinkedList *resultFrontList,
    LinkedList *resultBackList
);
```

### 요구사항

단일 연결 리스트를 앞 절반과 뒤 절반의 두 리스트로 나눈다.

- 원래 원소 순서를 유지한다.
- 원소 수가 홀수라면 **앞쪽 리스트가 하나 더 가진다.**
- 결과는 `resultFrontList`와 `resultBackList`로 전달한다.

### 예시

```text
입력: 2 → 3 → 5 → 6 → 7

앞 리스트: 2 → 3 → 5
뒤 리스트: 6 → 7
```

개수 기준으로는 5개일 때 `3 + 2`, 6개일 때 `3 + 3`이다.

**명시되지 않은 부분:** PDF 본문은 분리 이후 원본 `ll`의 상태나 노드 복사 여부를 명확하게 규정하지 않는다. 구현할 때 템플릿의 호출·메모리 해제 흐름과 함께 확인해야 한다.

## Q6. 최댓값 노드를 맨 앞으로 이동

원문 위치: 5~6쪽 · 함수: `moveMaxToFront`

```c
int moveMaxToFront(ListNode **ptrHead);
```

### 요구사항

정수 연결 리스트를 **최대 한 번 순회**하면서 가장 큰 값을 가진 노드를 찾아 리스트의 맨 앞으로 이동한다.

단순히 최댓값을 출력하거나 전체 리스트를 정렬하는 문제가 아니다. 최댓값이 저장된 **노드 자체를 이동**한다.

### 예시

```text
입력: 30 → 20 → 40 → 70 → 50
결과: 70 → 30 → 20 → 40 → 50
```

**명시되지 않은 부분:** 반환형은 `int`지만 PDF 본문에는 반환값의 의미가 설명되어 있지 않다. 최댓값이 여러 개일 때 어느 노드를 옮겨야 하는지도 명시되어 있지 않다.

## Q7. 재귀로 연결 리스트 뒤집기

원문 위치: 6쪽 · PDF 함수명: `recursiveReverse`

실제 C 파일의 선언:

```c
void RecursiveReverse(ListNode **ptrHead);
```

### 요구사항

재귀를 이용해 주어진 연결 리스트를 역순으로 바꾼다.

- **재귀 호출**을 사용한다.
- 각 노드의 **`next` 포인터와 리스트의 `head` 포인터를 변경**한다.
- 노드의 값만 교환하는 방식은 요구사항과 다르다.

### 예시

```text
입력: head → 1 → 2 → 3 → 4 → 5 → NULL
결과: head → 5 → 4 → 3 → 2 → 1 → NULL
```

기존 마지막 노드가 새로운 첫 노드가 되고, 기존 첫 노드는 새로운 마지막 노드가 된다.

## 읽기 위한 보충: 공통 구조

아래 내용은 PDF 문제 번역이 아니라, 제공된 C 코드를 이해하기 위한 설명이다.

```text
LinkedList
  size: 노드 개수
  head ──→ [item | next] ──→ [item | next] ──→ NULL
```

- `ListNode`: 값 `item`과 다음 노드의 주소 `next`를 담는 구조체.
- `LinkedList`: 리스트의 첫 노드 주소 `head`와 노드 개수 `size`를 담는 구조체.
- `LinkedList *ll`: 리스트 관리 구조체를 가리키는 포인터. 이를 통해 `head`나 `size`를 수정할 수 있다.
- `ListNode **ptrHead`: 첫 노드를 가리키는 포인터 변수의 주소. 함수 안에서 호출한 쪽의 `head`를 바꿀 수 있게 한다.
- `NULL`: 가리키는 노드가 없다는 표시. 빈 리스트의 `head`와 마지막 노드의 `next`에 사용한다.

## 직접 검증할 때 확인할 경우

아래는 PDF에 추가로 제안하는 테스트 관점이다.

- 공통: 빈 리스트, 노드 하나, 노드 여러 개.
- Q1: 맨 앞·중간·맨 뒤 삽입, 중복 입력.
- Q2: 두 리스트 길이가 같은 경우, 서로 다른 경우, 한쪽이 빈 경우.
- Q3·Q4: 전부 홀수, 전부 짝수, 섞인 경우, 0과 음수가 포함된 경우.
- Q5: 원소 개수가 짝수·홀수인 경우.
- Q6: 최댓값이 맨 앞·중간·맨 뒤에 있는 경우, 모두 음수인 경우.
- Q7: 뒤집은 리스트를 다시 뒤집었을 때 원래 순서로 돌아오는지.

연결을 바꾼 뒤에는 마지막 노드의 `next`가 `NULL`인지, 의도치 않은 순환이 생기지 않았는지, `size`가 실제 노드 개수와 맞는지도 확인한다.
